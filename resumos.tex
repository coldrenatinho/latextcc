\begin{resumo}
Este projeto propõe o desenvolvimento e a avaliação de um sistema inteligente de apoio à decisão para traders utilizando técnicas de Machine Learning aplicadas ao Minicontrato Futuro de Ibovespa (WIN). A pesquisa será baseada em dados históricos organizados temporalmente e em atributos derivados de preço, retorno, volume e indicadores técnicos. O problema será tratado prioritariamente como uma tarefa de classificação da direção futura do mercado. Serão comparados um modelo de referência e algoritmos de Machine Learning sob separação cronológica entre treinamento, validação e teste, com o objetivo de reduzir vazamento de informação e avaliar a capacidade de generalização. O desempenho será analisado por métricas de classificação, e os resultados serão integrados a um protótipo de apoio à decisão. O trabalho possui finalidade acadêmica e não pretende executar ordens automaticamente nem garantir rentabilidade financeira.

\textbf{Palavras-chave}: Mini Índice; WIN; Machine Learning; séries temporais financeiras; apoio à decisão.

\begin{otherlanguage*}{english}
This project proposes the development and evaluation of an intelligent decision support system for traders using Machine Learning techniques applied to the Mini Ibovespa Futures contract (WIN). The research will use chronologically organized historical data and features derived from price, returns, volume, and technical indicators. The main problem will be formulated as a classification task for future market direction. A baseline model and selected Machine Learning algorithms will be compared using chronological training, validation, and test partitions in order to reduce information leakage and evaluate generalization. Performance will be analyzed using classification metrics, and the results will be integrated into a decision support prototype. The study has an academic purpose and does not aim to execute orders automatically or guarantee financial returns.

\textbf{Keywords}: Mini Ibovespa Futures; WIN; Machine Learning; financial time series; decision support.
\end{otherlanguage*}
\end{resumo}
