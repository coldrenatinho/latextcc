\begin{resumo}
Este projeto apresenta o desenvolvimento e a avaliação do Estoque Fácil, um sistema web para gestão e controle de ativos. A pesquisa parte da identificação de demandas de softwares para gestão de estoque em pequenas empresas e médias empresas, como requisitos de implementação, tecnologias utilizadas e suas aplicações, arquitetura de software utilizadas, analise de infra-estrutura a ser implementadas e critérios de qualidade de software  orientam a construção da solução. O trabalho apresenta a fundamentação, o problema, a metodologia, o objeto de estudo e o planejamento de avaliação; resultados definitivos serão. O estudo também prevê a análise de soluções existentes, o registro de decisões arquiteturais e qualidade de software.
\begin{otherlanguage*}{english}
This project presents the development and evaluation of Estoque Fácil, a web system for inventory management and control. The research documents how domain demands, requirements, technologies, architecture and software quality criteria guide the construction of the solution. As a TCC I project, it presents the research foundation, methodology, object of study and evaluation plan; definitive results will be produced after the planned tests and instruments are applied.

\textbf{Keywords}: inventory management; web system; software engineering; software architecture; software quality.
\end{otherlanguage*}
\end{resumo}
